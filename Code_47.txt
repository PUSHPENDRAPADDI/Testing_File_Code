Creating an HR management application using Node.js with Express involves several steps, including setting up the server, defining routes, connecting to a database, and implementing the necessary business logic. Below is a simple example to get you started with a basic HR management application. 

### Requirements
Let's assume the application should handle the following functionalities:
1. Employee management (CRUD operations)
2. Department management (CRUD operations)
3. Basic authentication for access control

### Step-by-Step Implementation

#### 1. Set Up Your Environment
First, make sure you have Node.js and npm installed. Then, create a new directory for your project and initialize it.

```bash
mkdir hr-management-app
cd hr-management-app
npm init -y
```

#### 2. Install Required Packages
You will need Express, Mongoose (for MongoDB), and some other packages.

```bash
npm install express mongoose body-parser cors dotenv bcryptjs jsonwebtoken
```

#### 3. Create the Directory Structure
Create the following structure for your application:

```
hr-management-app/
├── models/
│   ├── employee.js
│   └── department.js
├── routes/
│   ├── employees.js
│   └── departments.js
├── middleware/
│   └── auth.js
├── .env
├── server.js
```

#### 4. Create Your Models
Define the Employee and Department models in the `models` directory.

**models/employee.js**
```javascript
const mongoose = require('mongoose');

const employeeSchema = new mongoose.Schema({
    name: { type: String, required: true },
    email: { type: String, required: true, unique: true },
    department: { type: mongoose.Schema.Types.ObjectId, ref: 'Department' },
    position: { type: String, required: true },
    dateOfJoining: { type: Date, default: Date.now },
});

module.exports = mongoose.model('Employee', employeeSchema);
```

**models/department.js**
```javascript
const mongoose = require('mongoose');

const departmentSchema = new mongoose.Schema({
    name: { type: String, required: true, unique: true },
    description: { type: String },
});

module.exports = mongoose.model('Department', departmentSchema);
```

#### 5. Create Your Routes
Define the routes for employees and departments.

**routes/employees.js**
```javascript
const express = require('express');
const Employee = require('../models/employee');
const router = express.Router();

// Create an employee
router.post('/', async (req, res) => {
    const employee = new Employee(req.body);
    try {
        const savedEmployee = await employee.save();
        res.status(201).json(savedEmployee);
    } catch (error) {
        res.status(400).json({ message: error.message });
    }
});

// Get all employees
router.get('/', async (req, res) => {
    try {
        const employees = await Employee.find().populate('department');
        res.json(employees);
    } catch (error) {
        res.status(500).json({ message: error.message });
    }
});

// Other CRUD operations (update, delete) can be added similarly

module.exports = router;
```

**routes/departments.js**
```javascript
const express = require('express');
const Department = require('../models/department');
const router = express.Router();

// Create a department
router.post('/', async (req, res) => {
    const department = new Department(req.body);
    try {
        const savedDepartment = await department.save();
        res.status(201).json(savedDepartment);
    } catch (error) {
        res.status(400).json({ message: error.message });
    }
});

// Get all departments
router.get('/', async (req, res) => {
    try {
        const departments = await Department.find();
        res.json(departments);
    } catch (error) {
        res.status(500).json({ message: error.message });
    }
});

// Other CRUD operations (update, delete) can be added similarly

module.exports = router;
```

#### 6. Set Up Middleware for Authentication (Optional)
You can create a simple authentication middleware in `middleware/auth.js` if you want to secure your routes.

```javascript
const jwt = require('jsonwebtoken');

const auth = (req, res, next) => {
    const token = req.header('Authorization').replace('Bearer ', '');
    if (!token) return res.status(401).send('Access denied.');

    try {
        const verified = jwt.verify(token, process.env.JWT_SECRET);
        req.user = verified;
        next();
    } catch (error) {
        res.status(400).send('Invalid token.');
    }
};

module.exports = auth;
```

#### 7. Create the Server Entry Point
Finally, set up your Express server in `server.js`.

**server.js**
```javascript
const express = require('express');
const mongoose = require('mongoose');
const bodyParser = require('body-parser');
const cors = require('cors');
const employeeRoutes = require('./routes/employees');
const departmentRoutes = require('./routes/departments');
require('dotenv').config();

const app = express();
app.use(cors());
app.use(bodyParser.json());

mongoose.connect(process.env.MONGO_URI, { useNewUrlParser: true, useUnifiedTopology: true })
    .then(() => console.log('MongoDB connected'))
    .catch(err => console.error(err));

app.use('/api/employees', employeeRoutes);
app.use('/api/departments', departmentRoutes);

const PORT = process.env.PORT || 5000;
app.listen(PORT, () => {
    console.log(`Server running on port ${PORT}`);
});
```

#### 8. Create a .env File
Don't forget to create a `.env` file in your root directory for environment variables.

```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

### Running the Application
1. Make sure your MongoDB server is running.
2. Start your application:

```bash
node server.js
```

### Final Notes
This is a basic structure for an HR management application using Node.js and Express. You can expand this by adding more features, such as user authentication, detailed error handling, input validation, and frontend integration. You might also consider using a frontend framework like React or Angular to build a user interface for your application.
