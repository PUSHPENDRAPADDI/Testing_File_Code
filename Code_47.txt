Creating a basic food delivery app in JavaScript involves several components, including the user interface (UI), handling data (like food items and orders), and possibly managing a backend (for persistent data storage). Below is a simplified example that demonstrates the core functionality of a food app using JavaScript, HTML, and CSS.

This example will include:
1. A list of food items.
2. An option to add items to a cart.
3. A simple cart display.

### 1. HTML Structure

Create an `index.html` file:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Food Delivery App</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <div class="container">
        <h1>Food Delivery App</h1>
        <div id="food-list" class="food-list"></div>
        <h2>Cart</h2>
        <div id="cart" class="cart"></div>
        <div id="total" class="total"></div>
    </div>

    <script src="app.js"></script>
</body>
</html>
```

### 2. CSS Styling

Create a `styles.css` file to style the application:

```css
body {
    font-family: Arial, sans-serif;
    background-color: #f8f9fa;
    margin: 0;
    padding: 20px;
}

.container {
    max-width: 800px;
    margin: auto;
}

.food-list, .cart {
    margin: 20px 0;
}

.food-item {
    padding: 10px;
    border: 1px solid #ccc;
    margin-bottom: 10px;
}

.cart-item {
    padding: 10px;
    border: 1px solid #007bff;
    margin-bottom: 10px;
    background-color: #e9ecef;
}
```

### 3. JavaScript Logic

Create an `app.js` file to handle the app logic:

```javascript
const foodItems = [
    { id: 1, name: "Pizza", price: 10.99 },
    { id: 2, name: "Burger", price: 8.99 },
    { id: 3, name: "Sushi", price: 12.99 },
    { id: 4, name: "Pasta", price: 9.99 },
];

let cart = [];

// Function to display food items
function displayFoodItems() {
    const foodList = document.getElementById('food-list');
    foodList.innerHTML = '';

    foodItems.forEach(item => {
        const foodItemDiv = document.createElement('div');
        foodItemDiv.className = 'food-item';
        foodItemDiv.innerHTML = `
            <h3>${item.name}</h3>
            <p>Price: $${item.price.toFixed(2)}</p>
            <button onclick="addToCart(${item.id})">Add to Cart</button>
        `;
        foodList.appendChild(foodItemDiv);
    });
}

// Function to add items to the cart
function addToCart(itemId) {
    const item = foodItems.find(i => i.id === itemId);
    cart.push(item);
    displayCart();
}

// Function to display the cart
function displayCart() {
    const cartDiv = document.getElementById('cart');
    const totalDiv = document.getElementById('total');
    cartDiv.innerHTML = '';
    
    cart.forEach(item => {
        const cartItemDiv = document.createElement('div');
        cartItemDiv.className = 'cart-item';
        cartItemDiv.innerHTML = `
            <h4>${item.name}</h4>
            <p>Price: $${item.price.toFixed(2)}</p>
        `;
        cartDiv.appendChild(cartItemDiv);
    });

    const total = cart.reduce((sum, item) => sum + item.price, 0);
    totalDiv.innerHTML = `<h3>Total: $${total.toFixed(2)}</h3>`;
}

// Initial call to display food items
displayFoodItems();
```

### Explanation

1. **HTML**: Sets up the structure of the app with sections for the food list and the cart.
2. **CSS**: Styles the elements for better presentation.
3. **JavaScript**: 
   - An array of food items is created.
   - Functions to display food items, add items to the cart, and display the cart are defined.
   - Each food item can be added to the cart, and the total price is calculated and displayed.

### To Run the App

1. Create the three files (`index.html`, `styles.css`, and `app.js`) in the same directory.
2. Open `index.html` in a web browser.

This is a very basic example. In a real-world application, you would likely want to implement features such as:
- User authentication
- Persistent data storage (using a backend service)
- Payment processing
- Responsive design for mobile users

Feel free to expand upon this foundation!
