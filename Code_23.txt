Below is a sample implementation of the Healthcare API System using FastAPI in Python. This code outlines the APIs specified in your Business Requirements Document (BRD) for patient management, appointment scheduling, electronic medical records (EMR), prescription management, and billing.

### FastAPI Implementation

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Dummy data storage
patients_db = {}
appointments_db = {}
records_db = {}
prescriptions_db = {}
billing_db = {}

# Models
class Patient(BaseModel):
    id: str
    name: str
    contact: str
    medical_history: Optional[str] = None

class Appointment(BaseModel):
    id: str
    patient_id: str
    doctor_id: str
    date: str
    status: str

class MedicalRecord(BaseModel):
    patient_id: str
    records: str

class Prescription(BaseModel):
    id: str
    patient_id: str
    doctor_id: str
    medication: str

class Invoice(BaseModel):
    id: str
    patient_id: str
    amount: float
    status: str

# Patient Management API
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    if patient.id in patients_db:
        raise HTTPException(status_code=400, detail="Patient already exists")
    patients_db[patient.id] = patient
    return patient

@app.get("/patients/{id}", response_model=Patient)
def get_patient(id: str):
    patient = patients_db.get(id)
    if not patient:
        raise HTTPException(status_code=404, detail="Patient not found")
    return patient

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: str, patient: Patient):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    patients_db[id] = patient
    return patient

@app.delete("/patients/{id}")
def deactivate_patient(id: str):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    del patients_db[id]
    return {"detail": "Patient deactivated"}

# Appointment Scheduling API
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    if appointment.id in appointments_db:
        raise HTTPException(status_code=400, detail="Appointment already exists")
    appointments_db[appointment.id] = appointment
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: str, appointment: Appointment):
    if id not in appointments_db:
        raise HTTPException(status_code=404, detail="Appointment not found")
    appointments_db[id] = appointment
    return appointment

@app.get("/doctors/{id}/availability")
def get_doctor_availability(id: str):
    # Dummy implementation for doctor's availability
    return {"doctor_id": id, "availability": "Available"}

# Electronic Medical Records (EMR) API
@app.get("/patients/{id}/records")
def get_medical_records(id: str):
    records = records_db.get(id)
    if not records:
        raise HTTPException(status_code=404, detail="Medical records not found")
    return records

@app.post("/patients/{id}/records", response_model=MedicalRecord)
def add_update_medical_records(id: str, records: MedicalRecord):
    records_db[id] = records
    return records

# Prescription Management API
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    if prescription.id in prescriptions_db:
        raise HTTPException(status_code=400, detail="Prescription already exists")
    prescriptions_db[prescription.id] = prescription
    return prescription

@app.get("/prescriptions/{id}")
def get_prescription(id: str):
    prescription = prescriptions_db.get(id)
    if not prescription:
        raise HTTPException(status_code=404, detail="Prescription not found")
    return prescription

# Billing & Insurance API
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    if invoice.id in billing_db:
        raise HTTPException(status_code=400, detail="Invoice already exists")
    billing_db[invoice.id] = invoice
    return invoice

@app.get("/billing/{id}")
def get_invoice(id: str):
    invoice = billing_db.get(id)
    if not invoice:
        raise HTTPException(status_code=404, detail="Invoice not found")
    return invoice

@app.post("/insurance/claims")
def process_insurance_claim(claim: Invoice):
    # Dummy implementation for insurance claims processing
    return {"detail": "Insurance claim processed"}

# Run the API with: uvicorn filename:app --reload
```

### Explanation:
- **Models**: The code defines Pydantic models for `Patient`, `Appointment`, `MedicalRecord`, `Prescription`, and `Invoice` to enforce data validation.
- **Endpoints**: Each functional requirement in the BRD has a corresponding FastAPI endpoint, allowing for CRUD operations.
- **Dummy Data Storage**: For simplicity, the implementation uses in-memory dictionaries to store the data. In a real-world application, you would connect to a database.
- **Error Handling**: The API raises HTTP exceptions for common error scenarios, such as trying to access or modify non-existent entries.

### Running the API
To run this FastAPI application:
1. Save the code to a file (e.g., `healthcare_api.py`).
2. Install FastAPI and Uvicorn if you haven't already:
   ```bash
   pip install fastapi uvicorn
   ```
3. Start the FastAPI server:
   ```bash
   uvicorn healthcare_api:app --reload
   ```

You can then access the API at `http://127.0.0.1:8000`, and the automatically generated documentation at `http://127.0.0.1:8000/docs`.
