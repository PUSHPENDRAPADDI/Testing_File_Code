To implement the specified requirements for a Healthcare API System using Node.js and Express, we will create an API structure that includes routes for patient management, appointment scheduling, electronic medical records (EMR), prescription management, and billing/insurance. Below is a basic outline of how you can set up the Express application along with the necessary routes.

### Setting Up the Express Application

1. **Install Node.js and Express**

Make sure you have Node.js installed on your machine. Then, create a new directory for your project and navigate to it. Run the following commands to initialize a new Node.js project and install Express:

```bash
mkdir healthcare-api
cd healthcare-api
npm init -y
npm install express body-parser cors mongoose
```

2. **Create the Basic Structure**

Create the following folder structure:

```
healthcare-api/
│
├── models/
│   ├── Patient.js
│   ├── Appointment.js
│   ├── EMR.js
│   ├── Prescription.js
│   └── Billing.js
│
├── routes/
│   ├── patientRoutes.js
│   ├── appointmentRoutes.js
│   ├── emrRoutes.js
│   ├── prescriptionRoutes.js
│   └── billingRoutes.js
│
├── controllers/
│   ├── patientController.js
│   ├── appointmentController.js
│   ├── emrController.js
│   ├── prescriptionController.js
│   └── billingController.js
│
├── app.js
└── package.json
```

3. **Create the Main Application File (`app.js`)**

Here's a basic setup for your Express application:

```javascript
// app.js
const express = require('express');
const bodyParser = require('body-parser');
const cors = require('cors');

const patientRoutes = require('./routes/patientRoutes');
const appointmentRoutes = require('./routes/appointmentRoutes');
const emrRoutes = require('./routes/emrRoutes');
const prescriptionRoutes = require('./routes/prescriptionRoutes');
const billingRoutes = require('./routes/billingRoutes');

const app = express();
const PORT = process.env.PORT || 3000;

// Middleware
app.use(cors());
app.use(bodyParser.json());

// Routes
app.use('/api/patients', patientRoutes);
app.use('/api/appointments', appointmentRoutes);
app.use('/api/emr', emrRoutes);
app.use('/api/prescriptions', prescriptionRoutes);
app.use('/api/billing', billingRoutes);

// Start the server
app.listen(PORT, () => {
    console.log(`Server is running on port ${PORT}`);
});
```

4. **Define Routes**

Create the route files under the `routes` directory. Below are examples of how to define the routes for `patientRoutes.js`. You would do something similar for the other route files.

```javascript
// routes/patientRoutes.js
const express = require('express');
const router = express.Router();
const patientController = require('../controllers/patientController');

// Register a new patient
router.post('/', patientController.registerPatient);

// Retrieve patient details
router.get('/:id', patientController.getPatientDetails);

// Update patient details
router.put('/:id', patientController.updatePatient);

// Deactivate patient profile
router.delete('/:id', patientController.deactivatePatient);

module.exports = router;
```

5. **Implement Controller Functions**

In the `controllers` directory, add the logic for each endpoint in the respective controller files. Below is an example for `patientController.js`.

```javascript
// controllers/patientController.js
const Patient = require('../models/Patient');

// Register a new patient
exports.registerPatient = async (req, res) => {
    try {
        const patient = new Patient(req.body);
        await patient.save();
        res.status(201).send(patient);
    } catch (error) {
        res.status(400).send(error);
    }
};

// Retrieve patient details
exports.getPatientDetails = async (req, res) => {
    try {
        const patient = await Patient.findById(req.params.id);
        if (!patient) {
            return res.status(404).send();
        }
        res.send(patient);
    } catch (error) {
        res.status(500).send(error);
    }
};

// Update patient details
exports.updatePatient = async (req, res) => {
    try {
        const patient = await Patient.findByIdAndUpdate(req.params.id, req.body, { new: true, runValidators: true });
        if (!patient) {
            return res.status(404).send();
        }
        res.send(patient);
    } catch (error) {
        res.status(400).send(error);
    }
};

// Deactivate patient profile
exports.deactivatePatient = async (req, res) => {
    try {
        const patient = await Patient.findByIdAndUpdate(req.params.id, { active: false });
        if (!patient) {
            return res.status(404).send();
        }
        res.send({ message: 'Patient deactivated successfully' });
    } catch (error) {
        res.status(500).send(error);
    }
};
```

6. **Define Models**

In the `models` directory, define your Mongoose models. Here's an example for the `Patient` model:

```javascript
// models/Patient.js
const mongoose = require('mongoose');

const patientSchema = new mongoose.Schema({
    name: { type: String, required: true },
    contact: { type: String, required: true },
    medicalHistory: { type: String },
    active: { type: Boolean, default: true }
});

module.exports = mongoose.model('Patient', patientSchema);
```

Repeat this for other models like `Appointment`, `EMR`, `Prescription`, and `Billing` according to the requirements outlined in your BRD.

7. **Connect to MongoDB**

You will need to connect your application to a MongoDB database. Include the connection logic in your `app.js` or create a separate `db.js` file to handle database connections.

```javascript
// db.js (this file is optional, can be included in app.js)
const mongoose = require('mongoose');

const connectDB = async () => {
    try {
        await mongoose.connect('mongodb://localhost:27017/healthcare', {
            useNewUrlParser: true,
            useUnifiedTopology: true,
        });
        console.log("MongoDB connected");
    } catch (error) {
        console.error("MongoDB connection error:", error);
        process.exit(1);
    }
};

module.exports = connectDB;
```

8. **Start the Server**

Finally, start your server with:

```bash
node app.js
```
