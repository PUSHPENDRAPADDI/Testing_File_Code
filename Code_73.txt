Creating a simple food delivery application in JavaScript involves several components, including the front-end (user interface) and back-end (server-side logic). Below, I'll provide a basic example of a food app using vanilla JavaScript for the front-end and Node.js with Express for the back-end. This will be a simple application that allows users to view a list of foods and place an order.

### 1. Front-End (HTML + JavaScript)

Here’s a simple HTML page with embedded JavaScript to display a list of foods:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Food Delivery App</title>
    <style>
        body { font-family: Arial, sans-serif; }
        .food-item { border: 1px solid #ccc; padding: 20px; margin: 10px; }
        .order-button { background-color: #28a745; color: white; border: none; padding: 10px; cursor: pointer; }
    </style>
</head>
<body>
    <h1>Food Delivery App</h1>
    <div id="food-list"></div>

    <script>
        async function fetchFoods() {
            const response = await fetch('http://localhost:3000/api/foods');
            const foods = await response.json();
            const foodList = document.getElementById('food-list');

            foods.forEach(food => {
                const foodItem = document.createElement('div');
                foodItem.className = 'food-item';
                foodItem.innerHTML = `
                    <h3>${food.name}</h3>
                    <p>Price: $${food.price}</p>
                    <button class="order-button" onclick="orderFood(${food.id})">Order</button>
                `;
                foodList.appendChild(foodItem);
            });
        }

        async function orderFood(foodId) {
            const response = await fetch(`http://localhost:3000/api/order`, {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                },
                body: JSON.stringify({ foodId }),
            });

            if (response.ok) {
                alert('Order placed successfully!');
            } else {
                alert('Failed to place order.');
            }
        }

        fetchFoods();
    </script>
</body>
</html>
```

### 2. Back-End (Node.js + Express)

Next, set up a simple back-end using Node.js and Express. First, make sure you have Node.js installed, and then create a new directory for your project. Inside that directory, run:

```bash
npm init -y
npm install express body-parser cors
```

Create a new file called `server.js` and add the following code:

```javascript
const express = require('express');
const bodyParser = require('body-parser');
const cors = require('cors');

const app = express();
const PORT = 3000;

// Middleware
app.use(cors());
app.use(bodyParser.json());

// Sample food data
let foods = [
    { id: 1, name: 'Pizza', price: 10.99 },
    { id: 2, name: 'Burger', price: 8.99 },
    { id: 3, name: 'Pasta', price: 12.99 }
];

// API to get foods
app.get('/api/foods', (req, res) => {
    res.json(foods);
});

// API to place an order
app.post('/api/order', (req, res) => {
    const { foodId } = req.body;
    const orderedFood = foods.find(food => food.id === foodId);
    
    if (orderedFood) {
        console.log(`Order placed for: ${orderedFood.name}`);
        return res.status(200).send('Order placed successfully!');
    }
    return res.status(404).send('Food not found.');
});

// Start the server
app.listen(PORT, () => {
    console.log(`Server is running on http://localhost:${PORT}`);
});
```

### 3. Running the Application

1. Start the server by running the following command in your terminal:

```bash
node server.js
```

2. Open the HTML file you created in a web browser. You should see a list of food items and be able to place orders.

### Note

- This is a basic example. In a production app, you would also want to handle errors, validate inputs, and possibly add a database for persistent storage.
- You can enhance the app by adding features like user authentication, order history, and payment processing.
