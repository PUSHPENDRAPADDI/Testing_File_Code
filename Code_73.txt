Certainly! Below is a sample implementation of a FastAPI application that outlines the structure of the APIs described in your Business Requirements Document (BRD) for a Healthcare API System. This implementation includes basic endpoints for patient management, appointment scheduling, electronic medical records, prescription management, and billing & insurance.

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Data Models
class Patient(BaseModel):
    id: int
    name: str
    contact_details: str
    medical_history: str

class Appointment(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    date: str
    time: str

class MedicalRecord(BaseModel):
    patient_id: int
    record_details: str

class Prescription(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    medication: str
    dosage: str

class Invoice(BaseModel):
    id: int
    patient_id: int
    amount: float
    status: str


# In-memory "databases"
patients_db = []
appointments_db = []
medical_records_db = []
prescriptions_db = []
invoices_db = []

@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    patients_db.append(patient)
    return patient

@app.get("/patients/{id}", response_model=Patient)
def retrieve_patient(id: int):
    for patient in patients_db:
        if patient.id == id:
            return patient
    raise HTTPException(status_code=404, detail="Patient not found")

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: int, updated_patient: Patient):
    for index, patient in enumerate(patients_db):
        if patient.id == id:
            patients_db[index] = updated_patient
            return updated_patient
    raise HTTPException(status_code=404, detail="Patient not found")

@app.delete("/patients/{id}", response_model=dict)
def deactivate_patient(id: int):
    for patient in patients_db:
        if patient.id == id:
            patients_db.remove(patient)
            return {"message": "Patient deactivated"}
    raise HTTPException(status_code=404, detail="Patient not found")

@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    appointments_db.append(appointment)
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: int, updated_appointment: Appointment):
    for index, appointment in enumerate(appointments_db):
        if appointment.id == id:
            appointments_db[index] = updated_appointment
            return updated_appointment
    raise HTTPException(status_code=404, detail="Appointment not found")

@app.get("/patients/{id}/records", response_model=List[MedicalRecord])
def retrieve_medical_records(id: int):
    records = [record for record in medical_records_db if record.patient_id == id]
    return records

@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    prescriptions_db.append(prescription)
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def retrieve_prescription(id: int):
    for prescription in prescriptions_db:
        if prescription.id == id:
            return prescription
    raise HTTPException(status_code=404, detail="Prescription not found")

@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    invoices_db.append(invoice)
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def retrieve_invoice(id: int):
    for invoice in invoices_db:
        if invoice.id == id:
            return invoice
    raise HTTPException(status_code=404, detail="Invoice not found")

# Run the app with: uvicorn filename:app --reload
```

### Explanation:
1. **Data Models**: The FastAPI app uses Pydantic models to define the structure of data for patients, appointments, medical records, prescriptions, and invoices.

2. **In-memory Databases**: For simplicity, we use lists to store data temporarily. In a real application, you'd want to connect to a persistent database.

3. **Endpoints**: Each endpoint is defined according to the requirements in the BRD. The endpoints allow for CRUD operations on patients, appointments, medical records, prescriptions, and invoices.

4. **Error Handling**: The application raises HTTP exceptions when a resource is not found, returning a 404 status code.

### Running the Application:
To run this FastAPI application, save the code to a file (e.g., `main.py`) and use the command:
```bash
uvicorn main:app --reload
```
This will start a development server, and you can test the APIs via a tool like Postman or cURL. FastAPI also provides an interactive API documentation at `http://127.0.0.1:8000/docs` where you can test the endpoints directly.
