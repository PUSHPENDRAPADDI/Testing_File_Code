Below is a basic implementation of the Healthcare API System using FastAPI. The code covers the endpoints defined in your Business Requirements Document (BRD) for patient management, appointment scheduling, electronic medical records (EMR), prescription management, and billing.

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Data Models
class Patient(BaseModel):
    id: int
    name: str
    contact_details: str
    medical_history: str

class Appointment(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    appointment_time: str
    status: str

class MedicalRecord(BaseModel):
    patient_id: int
    record_details: str

class Prescription(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    medication: str

class Invoice(BaseModel):
    id: int
    patient_id: int
    amount: float
    status: str

# In-memory storage (for simplicity)
patients_db = []
appointments_db = []
medical_records_db = []
prescriptions_db = []
invoices_db = []

# Patient Management APIs
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    patients_db.append(patient)
    return patient

@app.get("/patients/{id}", response_model=Patient)
def retrieve_patient(id: int):
    for patient in patients_db:
        if patient.id == id:
            return patient
    raise HTTPException(status_code=404, detail="Patient not found")

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: int, updated_patient: Patient):
    for index, patient in enumerate(patients_db):
        if patient.id == id:
            patients_db[index] = updated_patient
            return updated_patient
    raise HTTPException(status_code=404, detail="Patient not found")

@app.delete("/patients/{id}")
def deactivate_patient(id: int):
    for index, patient in enumerate(patients_db):
        if patient.id == id:
            patients_db.pop(index)
            return {"detail": "Patient deactivated"}
    raise HTTPException(status_code=404, detail="Patient not found")

# Appointment Scheduling APIs
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    appointments_db.append(appointment)
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_or_cancel_appointment(id: int, updated_appointment: Appointment):
    for index, appointment in enumerate(appointments_db):
        if appointment.id == id:
            appointments_db[index] = updated_appointment
            return updated_appointment
    raise HTTPException(status_code=404, detail="Appointment not found")

@app.get("/doctors/{id}/availability")
def retrieve_doctor_availability(id: int):
    # This is a placeholder; actual implementation should check doctor's schedule
    return {"doctor_id": id, "availability": "Available"}

# EMR APIs
@app.post("/patients/{id}/records", response_model=MedicalRecord)
def add_update_medical_record(id: int, record: MedicalRecord):
    medical_records_db.append(record)
    return record

@app.get("/patients/{id}/records", response_model=List[MedicalRecord])
def retrieve_medical_records(id: int):
    return [record for record in medical_records_db if record.patient_id == id]

# Prescription Management APIs
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    prescriptions_db.append(prescription)
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def retrieve_prescription(id: int):
    for prescription in prescriptions_db:
        if prescription.id == id:
            return prescription
    raise HTTPException(status_code=404, detail="Prescription not found")

# Billing & Insurance APIs
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    invoices_db.append(invoice)
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def retrieve_invoice(id: int):
    for invoice in invoices_db:
        if invoice.id == id:
            return invoice
    raise HTTPException(status_code=404, detail="Invoice not found")

@app.post("/insurance/claims")
def process_insurance_claim(claim: dict):
    # Placeholder for insurance claim processing logic
    return {"detail": "Insurance claim processed"}

# Run the application using `uvicorn` command:
# uvicorn filename:app --reload
```

### Instructions to Run the API
1. Save the code in a file, e.g., `healthcare_api.py`.
2. Install FastAPI and a server like Uvicorn:
   ```bash
   pip install fastapi uvicorn
   ```
3. Run the FastAPI application:
   ```bash
   uvicorn healthcare_api:app --reload
   ```
4. Access the API documentation at `http://127.0.0.1:8000/docs`.

### Notes
- This implementation uses in-memory storage (lists) for simplicity and demonstration purposes. In a production application, you would want to connect to a database.
- Each endpoint is implemented based on the specifications in the BRD.
- Additional functionalities such as authentication, authorization, error handling, and input validation can be built on top of this foundation.
