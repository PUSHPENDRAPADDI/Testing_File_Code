Creating a simple food delivery app using Express.js involves setting up a basic server, defining routes, and possibly connecting to a database. Below is a straightforward example that demonstrates how to create a minimal food app backend with Express.js.

### Prerequisites
- Node.js installed on your machine.
- Basic understanding of JavaScript and Express.js.
- A package manager like npm or yarn.

### Step 1: Initialize Your Project

First, create a new directory for your project and initialize it:

```bash
mkdir food-app
cd food-app
npm init -y
```

### Step 2: Install Dependencies

You will need Express.js and optionally a few other packages for this example:

```bash
npm install express body-parser cors
```

### Step 3: Create the Server

Create a file named `server.js` in your project directory:

```javascript
// server.js
const express = require('express');
const bodyParser = require('body-parser');
const cors = require('cors');

const app = express();
const PORT = process.env.PORT || 3000;

// Middleware
app.use(cors());
app.use(bodyParser.json());

// Sample data
let foods = [
    { id: 1, name: 'Pizza', price: 8.99 },
    { id: 2, name: 'Burger', price: 5.99 },
    { id: 3, name: 'Sushi', price: 12.99 },
];

// Routes
app.get('/api/foods', (req, res) => {
    res.json(foods);
});

app.post('/api/foods', (req, res) => {
    const newFood = {
        id: foods.length + 1,
        name: req.body.name,
        price: req.body.price,
    };
    foods.push(newFood);
    res.status(201).json(newFood);
});

app.get('/api/foods/:id', (req, res) => {
    const food = foods.find(f => f.id === parseInt(req.params.id));
    if (!food) return res.status(404).send('Food not found');
    res.json(food);
});

app.delete('/api/foods/:id', (req, res) => {
    const foodIndex = foods.findIndex(f => f.id === parseInt(req.params.id));
    if (foodIndex === -1) return res.status(404).send('Food not found');
    
    const deletedFood = foods.splice(foodIndex, 1);
    res.json(deletedFood);
});

// Start server
app.listen(PORT, () => {
    console.log(`Server is running on http://localhost:${PORT}`);
});
```

### Step 4: Run the Server

You can now run your server:

```bash
node server.js
```

### Step 5: Test Your API

You can use Postman or any other API testing tool to test your endpoints:

- **GET** `/api/foods` - Retrieves the list of foods.
- **POST** `/api/foods` - Adds a new food item. Send a JSON body like:
    ```json
    {
        "name": "Tacos",
        "price": 9.99
    }
    ```
- **GET** `/api/foods/:id` - Retrieves a specific food item by ID.
- **DELETE** `/api/foods/:id` - Deletes a specific food item by ID.

### Step 6: Enhancements

From here, you could add more features such as:

- User authentication (using JWT or sessions).
- A database (like MongoDB or PostgreSQL) to persist data instead of using in-memory storage.
- More complex routes for handling orders and customers.
- Frontend integration using a framework like React, Angular, or Vue.js.

This serves as a foundational example to get you started with building a food app using Express.js.
