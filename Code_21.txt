To implement a basic claim import solution using FastAPI in Python, we will create an API that receives claims data via a WebAPI, validates the XML format, matches existing patient and provider records, reprices the claim, and sends it back to the MPI Core system. Below is a simplified version of such an implementation.

### Prerequisites

1. Install FastAPI and an ASGI server like `uvicorn`:
   ```bash
   pip install fastapi uvicorn
   ```

2. Install `xmlschema` for XML validation:
   ```bash
   pip install xmlschema
   ```

3. Install `asyncpg` for PostgreSQL database interaction:
   ```bash
   pip install asyncpg
   ```

```python
@app.post("/claims/import")
async def import_claim(claim_xml: str):
    try:
        # Parse the XML
        root = ET.fromstring(claim_xml)
        claim_data = {
            "claim_id": root.find("claim_id").text,
            "patient_first_name": root.find("patient_first_name").text,
            "patient_last_name": root.find("patient_last_name").text,
            "patient_dob": root.find("patient_dob").text,
            "provider_tin": root.find("provider_tin").text,
            "provider_npi": root.find("provider_npi").text,
            "provider_last_name": root.find("provider_last_name").text,
            "amount": float(root.find("amount").text),
        }
        
        claim = Claim(**claim_data)

        # Validate patient
        if not await fetch_patient(claim.patient_first_name, claim.patient_last_name, claim.patient_dob):
            raise HTTPException(status_code=404, detail="Patient not found")

        # Validate provider
        if not await fetch_provider(claim.provider_tin, claim.provider_npi, claim.provider_last_name):
            raise HTTPException(status_code=404, detail="Provider not found")

        # Reprice the claim
        repriced_amount = await reprice_claim(claim)
        repriced_claim = RepricedClaim(claim_id=claim.claim_id, repriced_amount=repriced_amount, status="Processed")

        return repriced_claim
    except Exception as e:
        raise HTTPException(status_code=400, detail=str(e))

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

### Running the Application

1. Save the above two files in a directory named `claim_import`.
2. Set up your PostgreSQL database and adjust the `DATABASE_URL` in `main.py` as needed.
3. Run the FastAPI application:
   ```bash
   uvicorn main:app --reload
   ```
