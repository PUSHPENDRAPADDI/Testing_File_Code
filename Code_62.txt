Below is a basic implementation of a FastAPI application that could serve as the backend for the Claim Import POC using the OCI Platform as described in your Business Requirements Document (BRD). This implementation outlines the endpoints needed to receive claims, validate them, match patient and provider records, reprice claims, and send them back to the MPI Core System.

### FastAPI Implementation

1. **Install FastAPI and necessary libraries**:
   You need to install FastAPI and an ASGI server (like uvicorn) to run the application. You can do this with pip:

   ```bash
   pip install fastapi uvicorn psycopg2-binary lxml
   ```

2. **Create the FastAPI application**:

```python
from fastapi import FastAPI, HTTPException, UploadFile, File
from pydantic import BaseModel
from xml.etree import ElementTree as ET
import psycopg2

app = FastAPI()

# Database connection parameters
DB_HOST = "your_db_host"
DB_NAME = "your_db_name"
DB_USER = "your_db_user"
DB_PASS = "your_db_password"

# Pydantic model for Claim
class Claim(BaseModel):
    patient_first_name: str
    patient_last_name: str
    patient_dob: str
    provider_tin: str
    provider_npi: str
    provider_last_name: str
    claim_amount: float

@app.post("/receive_claims/")
async def receive_claims(file: UploadFile = File(...)):
    try:
        # Parse the XML file
        content = await file.read()
        root = ET.fromstring(content)

        claims = []
        for claim in root.findall('claim'):
            # Extract claim data here
            claim_data = Claim(
                patient_first_name=claim.find('patient_first_name').text,
                patient_last_name=claim.find('patient_last_name').text,
                patient_dob=claim.find('patient_dob').text,
                provider_tin=claim.find('provider_tin').text,
                provider_npi=claim.find('provider_npi').text,
                provider_last_name=claim.find('provider_last_name').text,
                claim_amount=float(claim.find('claim_amount').text)
            )
            claims.append(claim_data)

        # Validate and process claims
        processed_claims = []
        for claim in claims:
            patient_exists = validate_patient(claim)
            provider_exists = validate_provider(claim)
            if patient_exists and provider_exists:
                repriced_claim = reprice_claim(claim)
                processed_claims.append(repriced_claim)

        return {"status": "success", "processed_claims": processed_claims}

    except Exception as e:
        raise HTTPException(status_code=400, detail=str(e))

def validate_patient(claim: Claim) -> bool:
    # Implement patient validation logic, e.g., querying the database
    connection = psycopg2.connect(host=DB_HOST, database=DB_NAME, user=DB_USER, password=DB_PASS)
    cursor = connection.cursor()
    cursor.execute("SELECT * FROM patients WHERE first_name=%s AND last_name=%s AND dob=%s",
                   (claim.patient_first_name, claim.patient_last_name, claim.patient_dob))
    patient = cursor.fetchone()
    cursor.close()
    connection.close()
    return patient is not None

def validate_provider(claim: Claim) -> bool:
    # Implement provider validation logic, e.g., querying the database
    connection = psycopg2.connect(host=DB_HOST, database=DB_NAME, user=DB_USER, password=DB_PASS)
    cursor = connection.cursor()
    cursor.execute("SELECT * FROM providers WHERE tin=%s AND npi=%s AND last_name=%s",
                   (claim.provider_tin, claim.provider_npi, claim.provider_last_name))
    provider = cursor.fetchone()
    cursor.close()
    connection.close()
    return provider is not None

def reprice_claim(claim: Claim) -> dict:
    # Implement your repricing logic
    # This is a mock repricing logic
    repriced_amount = claim.claim_amount * 0.8  # Example: 20% discount
    return {
        "patient": f"{claim.patient_first_name} {claim.patient_last_name}",
        "provider": f"{claim.provider_last_name}",
        "original_amount": claim.claim_amount,
        "repriced_amount": repriced_amount
    }

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

### Explanation of the Code:

1. **FastAPI Application**: The application creates a FastAPI instance to handle HTTP requests.

2. **Claim Model**: A Pydantic model defines the structure of the claim data. This helps with data validation.

3. **Receive Claims Endpoint**: The `/receive_claims/` endpoint accepts an XML file, parses it, and extracts claim data. It validates each claim against the patient and provider records.

4. **Validation Functions**: The `validate_patient` and `validate_provider` functions query a PostgreSQL database to check if the given patient and provider exist.

5. **Repricing Logic**: The `reprice_claim` function contains simple logic to reprice the claim. You would replace this with your actual repricing logic.

6. **Running the Server**: The application runs on `0.0.0.0:8000`, and you can access it by sending POST requests to the `/receive_claims/` endpoint with an XML file.
