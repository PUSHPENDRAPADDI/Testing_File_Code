Certainly! Below is an example implementation of a basic FastAPI application that outlines the APIs defined in your Business Requirements Document (BRD) for a healthcare API system. The implementation includes endpoints for patient management, appointment scheduling, electronic medical records (EMR), prescription management, and billing.

### FastAPI Implementation

To get started, make sure you have FastAPI and a suitable ASGI server (like `uvicorn`) installed. You can install them using pip:

```bash
pip install fastapi uvicorn
```

Then, create a file named `main.py` and add the following code:

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Mock databases
patients_db = {}
appointments_db = {}
emr_db = {}
prescriptions_db = {}
billing_db = {}

# Models
class Patient(BaseModel):
    id: int
    name: str
    contact: str
    medical_history: str

class Appointment(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    date_time: str
    status: str

class MedicalRecord(BaseModel):
    patient_id: int
    record: str

class Prescription(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    prescription: str

class Invoice(BaseModel):
    id: int
    patient_id: int
    amount: float
    status: str

# Patient Management
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    if patient.id in patients_db:
        raise HTTPException(status_code=400, detail="Patient already exists.")
    patients_db[patient.id] = patient
    return patient

@app.get("/patients/{id}", response_model=Patient)
def get_patient(id: int):
    patient = patients_db.get(id)
    if not patient:
        raise HTTPException(status_code=404, detail="Patient not found.")
    return patient

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: int, patient: Patient):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found.")
    patients_db[id] = patient
    return patient

@app.delete("/patients/{id}", response_model=dict)
def deactivate_patient(id: int):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found.")
    del patients_db[id]
    return {"detail": "Patient profile deactivated."}

# Appointment Scheduling
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    if appointment.id in appointments_db:
        raise HTTPException(status_code=400, detail="Appointment already exists.")
    appointments_db[appointment.id] = appointment
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: int, appointment: Appointment):
    if id not in appointments_db:
        raise HTTPException(status_code=404, detail="Appointment not found.")
    appointments_db[id] = appointment
    return appointment

@app.get("/doctors/{id}/availability")
def get_doctor_availability(id: int):
    # This is a placeholder for doctor availability logic
    return {"doctor_id": id, "available": True}

# Electronic Medical Records (EMR)
@app.get("/patients/{id}/records", response_model=List[MedicalRecord])
def get_medical_records(id: int):
    records = [record for record in emr_db.get(id, [])]
    return records

@app.post("/patients/{id}/records", response_model=MedicalRecord)
def add_medical_record(id: int, record: MedicalRecord):
    if id not in emr_db:
        emr_db[id] = []
    emr_db[id].append(record)
    return record

# Prescription Management
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    if prescription.id in prescriptions_db:
        raise HTTPException(status_code=400, detail="Prescription already exists.")
    prescriptions_db[prescription.id] = prescription
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def get_prescription(id: int):
    prescription = prescriptions_db.get(id)
    if not prescription:
        raise HTTPException(status_code=404, detail="Prescription not found.")
    return prescription

# Billing & Insurance
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    if invoice.id in billing_db:
        raise HTTPException(status_code=400, detail="Invoice already exists.")
    billing_db[invoice.id] = invoice
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def get_invoice(id: int):
    invoice = billing_db.get(id)
    if not invoice:
        raise HTTPException(status_code=404, detail="Invoice not found.")
    return invoice

# To run the API, use the command:
# uvicorn main:app --reload
```

### Running the Application

To run the FastAPI application, execute the following command in your terminal:

```bash
uvicorn main:app --reload
```

### Testing the API

You can test the API using tools like Postman, curl, or directly through the automatically generated documentation provided by FastAPI. Navigate to `http://127.0.0.1:8000/docs` to see the interactive API documentation.

### Note

This implementation is basic and does not include persistent storage (like a database), authentication, or detailed error handling. For a production-ready application, consider integrating a database, implementing security features like OAuth2, and validating input more robustly.
