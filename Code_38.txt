Below is an implementation of the Healthcare API System described in your Business Requirements Document (BRD) using FastAPI, a modern web framework for building APIs in Python. This example covers the core functionalities outlined in the BRD, including Patient Management, Appointment Scheduling, Electronic Medical Records (EMR), Prescription Management, and Billing & Insurance.

### FastAPI Implementation

```python
from fastapi import FastAPI, HTTPException, Depends
from pydantic import BaseModel
from typing import List, Optional
from datetime import datetime
from uuid import UUID, uuid4

app = FastAPI()

# In-memory storage for demonstration (to be replaced with a database in production)
patients_db = {}
appointments_db = {}
records_db = {}
prescriptions_db = {}
billing_db = {}

# Models
class Patient(BaseModel):
    id: UUID = uuid4()
    name: str
    contact_details: str
    medical_history: Optional[str] = None

class Appointment(BaseModel):
    id: UUID = uuid4()
    patient_id: UUID
    doctor_id: str
    scheduled_time: datetime

class MedicalRecord(BaseModel):
    patient_id: UUID
    record_details: str

class Prescription(BaseModel):
    id: UUID = uuid4()
    patient_id: UUID
    medication: str
    dosage: str

class Invoice(BaseModel):
    id: UUID = uuid4()
    patient_id: UUID
    amount: float
    status: str

# Patient Management API
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    patients_db[patient.id] = patient
    return patient

@app.get("/patients/{id}", response_model=Patient)
def get_patient(id: UUID):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    return patients_db[id]

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: UUID, patient: Patient):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    patients_db[id] = patient
    return patient

@app.delete("/patients/{id}", response_model=dict)
def deactivate_patient(id: UUID):
    if id in patients_db:
        del patients_db[id]
        return {"detail": "Patient profile deactivated"}
    raise HTTPException(status_code=404, detail="Patient not found")

# Appointment Scheduling API
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    appointments_db[appointment.id] = appointment
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: UUID, appointment: Appointment):
    if id not in appointments_db:
        raise HTTPException(status_code=404, detail="Appointment not found")
    appointments_db[id] = appointment
    return appointment

@app.get("/doctors/{id}/availability", response_model=List[datetime])
def get_doctor_availability(id: str):
    # Placeholder for doctor availability logic
    return [datetime.now()]  # Return current time as a placeholder

# EMR API
@app.get("/patients/{id}/records", response_model=List[MedicalRecord])
def get_medical_records(id: UUID):
    return [record for record in records_db.values() if record.patient_id == id]

@app.post("/patients/{id}/records", response_model=MedicalRecord)
def add_medical_record(id: UUID, record: MedicalRecord):
    record.patient_id = id
    records_db[uuid4()] = record
    return record

# Prescription Management API
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    prescriptions_db[prescription.id] = prescription
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def get_prescription(id: UUID):
    if id not in prescriptions_db:
        raise HTTPException(status_code=404, detail="Prescription not found")
    return prescriptions_db[id]

# Billing & Insurance API
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    billing_db[invoice.id] = invoice
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def get_invoice(id: UUID):
    if id not in billing_db:
        raise HTTPException(status_code=404, detail="Invoice not found")
    return billing_db[id]

@app.post("/insurance/claims", response_model=dict)
def process_insurance_claim(invoice_id: UUID):
    # Placeholder for claims processing logic
    return {"detail": "Insurance claim processed"}

# To run the API, use the command:
# uvicorn main:app --reload
```

### Explanation
1. **FastAPI**: The code uses the FastAPI framework, which is designed for building APIs quickly and easily.
2. **Models**: Data models (e.g., `Patient`, `Appointment`, `MedicalRecord`, `Prescription`, `Invoice`) are defined using Pydantic, ensuring data validation and serialization.
3. **In-Memory Database**: For simplicity, an in-memory dictionary is used to store patient data, appointments, medical records, prescriptions, and invoices. In a production environment, this should be replaced with a proper database (e.g., PostgreSQL, MongoDB).
4. **API Endpoints**: The code defines endpoints for each of the functional requirements outlined in the BRD, including CRUD operations for patients, appointments, records, prescriptions, and billing.
5. **Error Handling**: The code includes error handling using `HTTPException` to manage cases where resources are not found.

### Running the API
To run this FastAPI application, save the code in a file named `main.py`, and use the command:
```bash
uvicorn main:app --reload
```
This will start the FastAPI server, and you can interact with the API through the automatically generated documentation at `http://127.0.0.1:8000/docs`.
