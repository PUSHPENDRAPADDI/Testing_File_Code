To create an Express.js application that implements the given API requirements for the Healthcare API System, we will set up routes and controllers for each of the specified modules. Below is a basic structure for the Express application, including routes and example controller functions for each API module.

### Step 1: Initialize a new Node.js project

First, create a new directory for your project and initialize a Node.js application:

```bash
mkdir healthcare-api
cd healthcare-api
npm init -y
```

### Step 2: Install Dependencies

You will need Express and other middleware for your application:

```bash
npm install express body-parser mongoose cors dotenv
```

### Step 4: Create Model Schemas (Example)

Here’s a simple example for the Patient model using Mongoose (you can define similar models for other entities):

**models/patient.js**
```javascript
const mongoose = require('mongoose');

const PatientSchema = new mongoose.Schema({
    personalInfo: {
        name: String,
        contact: String,
        // Add more fields as necessary
    },
    medicalHistory: [String], // Array of medical history records
    isActive: { type: Boolean, default: true }
});

module.exports = mongoose.model('Patient', PatientSchema);
```

### Step 5: Create Controllers (Example)

Here’s an example of the Patient controller:

**controllers/patientController.js**
```javascript
const Patient = require('../models/patient');

// Register a new patient
exports.registerPatient = async (req, res) => {
    try {
        const patient = new Patient(req.body);
        await patient.save();
        res.status(201).json(patient);
    } catch (error) {
        res.status(400).json({ message: error.message });
    }
};

// Retrieve patient details
exports.getPatientDetails = async (req, res) => {
    try {
        const patient = await Patient.findById(req.params.id);
        if (!patient) return res.status(404).json({ message: 'Patient not found' });
        res.json(patient);
    } catch (error) {
        res.status(500).json({ message: error.message });
    }
};

// Update patient details
exports.updatePatientDetails = async (req, res) => {
    try {
        const patient = await Patient.findByIdAndUpdate(req.params.id, req.body, { new: true });
        if (!patient) return res.status(404).json({ message: 'Patient not found' });
        res.json(patient);
    } catch (error) {
        res.status(400).json({ message: error.message });
    }
};

// Deactivate patient profile
exports.deactivatePatient = async (req, res) => {
    try {
        const patient = await Patient.findByIdAndUpdate(req.params.id, { isActive: false }, { new: true });
        if (!patient) return res.status(404).json({ message: 'Patient not found' });
        res.json(patient);
    } catch (error) {
        res.status(400).json({ message: error.message });
    }
};
```

### Step 6: Create Routes (Example)

Here’s how to set up the routes for the Patient module:

**routes/patientRoutes.js**
```javascript
const express = require('express');
const router = express.Router();
const patientController = require('../controllers/patientController');

router.post('/', patientController.registerPatient);
router.get('/:id', patientController.getPatientDetails);
router.put('/:id', patientController.updatePatientDetails);
router.delete('/:id', patientController.deactivatePatient);

module.exports = router;
```

### Step 7: Set Up Main Server File

**server.js**
```javascript
const express = require('express');
const mongoose = require('mongoose');
const bodyParser = require('body-parser');
const cors = require('cors');
const dotenv = require('dotenv');

dotenv.config();

const app = express();
const PORT = process.env.PORT || 5000;

// Middleware
app.use(cors());
app.use(bodyParser.json());

// MongoDB connection
mongoose.connect(process.env.MONGO_URI, { useNewUrlParser: true, useUnifiedTopology: true })
    .then(() => console.log('MongoDB connected'))
    .catch(err => console.log(err));

// Import routes
const patientRoutes = require('./routes/patientRoutes');
// Import other routes (appointments, billing, EMR, prescriptions)

// Use routes
app.use('/patients', patientRoutes);
// app.use('/appointments', appointmentRoutes);
// app.use('/billing', billingRoutes);
// app.use('/emr', emrRoutes);
// app.use('/prescriptions', prescriptionRoutes);

app.listen(PORT, () => {
    console.log(`Server is running on port ${PORT}`);
});
```

### Step 8: Create .env File

Create a `.env` file in the root directory to store environment variables:

```
MONGO_URI=mongodb://<username>:<password>@localhost:27017/healthcare_db
PORT=5000
```

### Step 9: Run the Application

Now you can run your application:

```bash
node server.js
```

### Note
This is a basic setup, and you would need to implement similar controllers and routes for the other modules (appointments, EMR, prescriptions, billing). Additionally, consider implementing error handling, validation, authentication (e.g., OAuth 2.0/JWT), and unit tests for a production-ready application.
