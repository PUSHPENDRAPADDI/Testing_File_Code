Certainly! Below is an example of how to implement the API endpoints specified in the Business Requirements Document (BRD) using FastAPI in Python. 

This implementation includes basic CRUD operations for Patient Management, Appointment Scheduling, Electronic Medical Records (EMR), Prescription Management, and Billing & Insurance. Please note that this is a simplified version and does not include database integration or full authentication mechanisms. 

### FastAPI Implementation

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Data models
class Patient(BaseModel):
    id: int
    name: str
    contact: str
    medical_history: List[str]

class Appointment(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    date: str
    time: str

class MedicalRecord(BaseModel):
    patient_id: int
    record: str

class Prescription(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    medication: str
    dosage: str

class Invoice(BaseModel):
    id: int
    patient_id: int
    amount: float
    status: str

# In-memory databases (for demonstration only)
patients_db = {}
appointments_db = {}
medical_records_db = {}
prescriptions_db = {}
invoices_db = {}

# Patient Management Endpoints
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    if patient.id in patients_db:
        raise HTTPException(status_code=400, detail="Patient already exists.")
    patients_db[patient.id] = patient
    return patient

@app.get("/patients/{id}", response_model=Patient)
def get_patient(id: int):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found.")
    return patients_db[id]

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: int, patient: Patient):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found.")
    patients_db[id] = patient
    return patient

@app.delete("/patients/{id}")
def deactivate_patient(id: int):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found.")
    del patients_db[id]
    return {"detail": "Patient profile deactivated."}

# Appointment Scheduling Endpoints
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    if appointment.id in appointments_db:
        raise HTTPException(status_code=400, detail="Appointment already exists.")
    appointments_db[appointment.id] = appointment
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: int, appointment: Appointment):
    if id not in appointments_db:
        raise HTTPException(status_code=404, detail="Appointment not found.")
    appointments_db[id] = appointment
    return appointment

@app.get("/doctors/{id}/availability")
def get_doctor_availability(id: int):
    # Dummy implementation for doctor availability
    return {"doctor_id": id, "available": True}

# EMR Endpoints
@app.get("/patients/{id}/records", response_model=List[MedicalRecord])
def get_medical_records(id: int):
    return [record for record in medical_records_db.values() if record.patient_id == id]

@app.post("/patients/{id}/records", response_model=MedicalRecord)
def add_medical_record(id: int, record: MedicalRecord):
    medical_records_db.append(record)
    return record

# Prescription Management Endpoints
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    if prescription.id in prescriptions_db:
        raise HTTPException(status_code=400, detail="Prescription already exists.")
    prescriptions_db[prescription.id] = prescription
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def retrieve_prescription(id: int):
    if id not in prescriptions_db:
        raise HTTPException(status_code=404, detail="Prescription not found.")
    return prescriptions_db[id]

# Billing & Insurance Endpoints
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    if invoice.id in invoices_db:
        raise HTTPException(status_code=400, detail="Invoice already exists.")
    invoices_db[invoice.id] = invoice
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def get_invoice(id: int):
    if id not in invoices_db:
        raise HTTPException(status_code=404, detail="Invoice not found.")
    return invoices_db[id]

@app.post("/insurance/claims")
def process_insurance_claim(claim_data: dict):
    # Dummy implementation for insurance claim processing
    return {"detail": "Insurance claim processed."}

# Run the FastAPI application
if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

### Explanation

- **Data Models**: Pydantic models are defined for `Patient`, `Appointment`, `MedicalRecord`, `Prescription`, and `Invoice`.
- **In-Memory Databases**: For demonstration, dictionaries are used to store data in memory.
- **Endpoints**: Each section of the API corresponds to the functional requirements outlined in the BRD:
  - Patient Management: Create, retrieve, update, and delete patient profiles.
  - Appointment Scheduling: Schedule, modify, and check doctor availability for appointments.
  - EMR: Retrieve and update medical records.
  - Prescription Management: Generate and retrieve prescriptions.
  - Billing & Insurance: Generate and retrieve invoices, and process insurance claims.

### Running the Application
To run the application, ensure you have `FastAPI` and `uvicorn` installed. You can install them using pip:

```bash
pip install fastapi uvicorn
```

Then, run the FastAPI application:

```bash
python your_file_name.py
```

You can access the API documentation at `http://127.0.0.1:8000/docs` once the server is running. 

### Note
Remember that this is a simplified example. In a production environment, you would typically integrate it with a database, implement authentication and authorization, and ensure compliance with relevant regulations.
