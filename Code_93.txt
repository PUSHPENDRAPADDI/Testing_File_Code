### User Story
As a user, I want to be able to create, update, and retrieve client profiles so that I can manage client information effectively.

### Test Cases
1. **Test Case 1: Create a new client profile**
   - Input: Client data (name, email, phone)
   - Expected Output: Success message and the created client profile.

2. **Test Case 2: Update an existing client profile**
   - Input: Client ID and updated data
   - Expected Output: Success message and the updated client profile.

3. **Test Case 3: Retrieve a client profile by ID**
   - Input: Client ID
   - Expected Output: The client profile data.

4. **Test Case 4: Handle non-existent client profile retrieval**
   - Input: Non-existent Client ID
   - Expected Output: Error message indicating the client was not found.

### Code Implementation

```python
# client_profile_manager.py

class ClientProfile:
    def __init__(self, client_id, name, email, phone):
        self.client_id = client_id
        self.name = name
        self.email = email
        self.phone = phone

    def __repr__(self):
        return f"ClientProfile(client_id={self.client_id}, name={self.name}, email={self.email}, phone={self.phone})"


class ClientProfileManager:
    def __init__(self):
        self.client_profiles = {}
        self.current_id = 1

    def create_client_profile(self, name, email, phone):
        client_profile = ClientProfile(self.current_id, name, email, phone)
        self.client_profiles[self.current_id] = client_profile
        self.current_id += 1
        return {"message": "Client profile created successfully", "profile": client_profile}

    def update_client_profile(self, client_id, name=None, email=None, phone=None):
        if client_id not in self.client_profiles:
            return {"error": "Client profile not found"}
        
        profile = self.client_profiles[client_id]
        if name:
            profile.name = name
        if email:
            profile.email = email
        if phone:
            profile.phone = phone
        
        return {"message": "Client profile updated successfully", "profile": profile}

    def get_client_profile(self, client_id):
        if client_id not in self.client_profiles:
            return {"error": "Client profile not found"}
        
        return {"profile": self.client_profiles[client_id]}


# Example usage
if __name__ == "__main__":
    manager = ClientProfileManager()

    # Test Case 1: Create a new client profile
    print(manager.create_client_profile("John Doe", "john@example.com", "123-456-7890"))

    # Test Case 2: Update an existing client profile
    print(manager.update_client_profile(1, email="john.doe@example.com"))

    # Test Case 3: Retrieve a client profile by ID
    print(manager.get_client_profile(1))

    # Test Case 4: Handle non-existent client profile retrieval
    print(manager.get_client_profile(99))
```

### Explanation
1. **ClientProfile Class**: Represents a client profile with attributes such as `client_id`, `name`, `email`, and `phone`.
2. **ClientProfileManager Class**: Contains methods for creating, updating, and retrieving client profiles.
   - `create_client_profile`: Creates a new client profile and assigns a unique ID.
   - `update_client_profile`: Updates an existing client profile based on the provided `client_id`.
   - `get_client_profile`: Retrieves a client profile by its ID and handles cases where the profile does not exist.
3. **Example Usage**: Demonstrates how to use the `ClientProfileManager` class with test cases outlined in the user story.
