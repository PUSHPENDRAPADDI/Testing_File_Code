To create a React.js component for the login screen based on the provided Figma metadata, we will break it down into a React component and a separate CSS file for styling. Below is an example of how you can structure your code:

### 1. Create the React Component

```jsx
// LoginScreen.jsx
import React from 'react';
import './LoginScreen.css';

const LoginScreen = () => {
    return (
        <div className="login-container">
            <h1 className="login-title">Login Screen</h1>
            <div className="input-group">
                <label htmlFor="email" className="input-label">Email:</label>
                <input type="email" id="email" className="input-field" />
            </div>
            <div className="input-group">
                <label htmlFor="password" className="input-label">Password:</label>
                <input type="password" id="password" className="input-field" />
            </div>
            <button className="submit-button">Submit</button>
        </div>
    );
};

export default LoginScreen;
```

### 3. How to Use the Component

You can now use the `LoginScreen` component in your main application file or wherever you want to display the login screen:

```jsx
// App.jsx
import React from 'react';
import LoginScreen from './LoginScreen';

const App = () => {
    return (
        <div>
            <LoginScreen />
        </div>
    );
};

export default App;
```

### Note:
- Make sure you have the "Inter" font available in your project. You can include it in your `index.html` or import it in your CSS file.
- Adjust the styles as needed to match your design from Figma more closely or according to your application's design system.
