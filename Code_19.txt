
Here’s the code for the FastAPI application:

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Sample Data Stores
patients_db = {}
appointments_db = {}
records_db = {}
prescriptions_db = {}
billing_db = {}

# Models
class Patient(BaseModel):
    id: int
    name: str
    age: int
    medical_history: str

class Appointment(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    date_time: str

class MedicalRecord(BaseModel):
    patient_id: int
    record: str

class Prescription(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    medication: str

class Invoice(BaseModel):
    id: int
    patient_id: int
    amount: float
    status: str

# 3.1 Patient Management API
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    if patient.id in patients_db:
        raise HTTPException(status_code=400, detail="Patient already exists")
    patients_db[patient.id] = patient
    return patient

@app.get("/patients/{id}", response_model=Patient)
def get_patient(id: int):
    patient = patients_db.get(id)
    if not patient:
        raise HTTPException(status_code=404, detail="Patient not found")
    return patient

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: int, patient: Patient):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    patients_db[id] = patient
    return patient

@app.delete("/patients/{id}")
def deactivate_patient(id: int):
    if id in patients_db:
        del patients_db[id]
        return {"detail": "Patient deactivated"}
    raise HTTPException(status_code=404, detail="Patient not found")

# 3.2 Appointment Scheduling API
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    if appointment.id in appointments_db:
        raise HTTPException(status_code=400, detail="Appointment already exists")
    appointments_db[appointment.id] = appointment
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: int, appointment: Appointment):
    if id not in appointments_db:
        raise HTTPException(status_code=404, detail="Appointment not found")
    appointments_db[id] = appointment
    return appointment

@app.get("/doctors/{doctor_id}/availability")
def get_doctor_availability(doctor_id: int):
    # Dummy implementation - in real scenarios, check for actual availability
    return {"available": True}

# 3.3 Electronic Medical Records (EMR) API
@app.get("/patients/{patient_id}/records", response_model=List[MedicalRecord])
def get_medical_records(patient_id: int):
    records = [record for record in records_db.values() if record.patient_id == patient_id]
    return records

@app.post("/patients/{patient_id}/records", response_model=MedicalRecord)
def add_medical_record(patient_id: int, record: MedicalRecord):
    record.patient_id = patient_id
    records_db[len(records_db) + 1] = record
    return record

# 3.4 Prescription Management API
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    prescriptions_db[len(prescriptions_db) + 1] = prescription
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def get_prescription(id: int):
    prescription = prescriptions_db.get(id)
    if not prescription:
        raise HTTPException(status_code=404, detail="Prescription not found")
    return prescription

# 3.5 Billing & Insurance API
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    billing_db[len(billing_db) + 1] = invoice
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def get_invoice(id: int):
    invoice = billing_db.get(id)
    if not invoice:
        raise HTTPException(status_code=404, detail="Invoice not found")
    return invoice

@app.post("/insurance/claims")
def process_insurance_claim(claim: dict):
    # Dummy implementation for processing claims
    return {"detail": "Insurance claim processed"}

# Run with: uvicorn filename:app --reload
```

### How to Run the Application
1. Save the above code in a file named `main.py`.
2. Run the FastAPI application using Uvicorn:

```bash
uvicorn main:app --reload
```

3. Open your browser and navigate to `http://127.0.0.1:8000/docs` to access the interactive API documentation generated by FastAPI.

### Notes
- This implementation uses in-memory dictionaries for data storage. In a production environment, you would typically use a database (e.g., PostgreSQL, MongoDB).
- The authentication and authorization aspects (OAuth2/JWT) are not included in this basic example but are essential for a production system, especially in healthcare applications.
- Error handling is implemented for basic CRUD operations, but you may want to expand this further based on your needs.

Feel free to modify or expand upon this code based on your specific requirements!
