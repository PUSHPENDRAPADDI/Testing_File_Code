Creating a hotel management application using Express.js involves setting up a web server and defining routes for various functionalities, such as managing bookings, rooms, customers, and payments. Below, I'll provide a basic structure and example code snippets to get you started.

### Requirements
For this example, let's assume the following basic requirements for your hotel management application:

1. **Room Management**: Add, update, delete, and view rooms.
2. **Booking Management**: Create, update, cancel, and view bookings.
3. **Customer Management**: Add, update, delete, and view customers.
4. **Payment Management**: Process payments for bookings.

### Project Structure
```
hotel-management-app/
├── models/
│   ├── Room.js
│   ├── Booking.js
│   └── Customer.js
├── routes/
│   ├── rooms.js
│   ├── bookings.js
│   └── customers.js
├── controllers/
│   ├── roomController.js
│   ├── bookingController.js
│   └── customerController.js
├── app.js
└── package.json
```

### Step 1: Setup Express Application
First, create a new directory for your project and initialize it with npm:

```bash
mkdir hotel-management-app
cd hotel-management-app
npm init -y
npm install express body-parser mongoose
```

### Step 2: Create the Express Server (app.js)
In the `app.js` file, set up the basic Express server:

```javascript
const express = require('express');
const bodyParser = require('body-parser');
const mongoose = require('mongoose');

const app = express();
const PORT = process.env.PORT || 3000;

// Middleware
app.use(bodyParser.json());

// MongoDB connection
mongoose.connect('mongodb://localhost:27017/hotelManagement', {
    useNewUrlParser: true,
    useUnifiedTopology: true,
});

// Routes
const roomRoutes = require('./routes/rooms');
const bookingRoutes = require('./routes/bookings');
const customerRoutes = require('./routes/customers');

app.use('/api/rooms', roomRoutes);
app.use('/api/bookings', bookingRoutes);
app.use('/api/customers', customerRoutes);

app.listen(PORT, () => {
    console.log(`Server is running on port ${PORT}`);
});
```

### Step 3: Create Models
Create Mongoose models for `Room`, `Booking`, and `Customer` in the `models` directory.

**models/Room.js**
```javascript
const mongoose = require('mongoose');

const roomSchema = new mongoose.Schema({
    roomNumber: { type: String, required: true },
    type: { type: String, required: true },
    price: { type: Number, required: true },
    status: { type: String, default: 'available' },
});

module.exports = mongoose.model('Room', roomSchema);
```

**models/Booking.js**
```javascript
const mongoose = require('mongoose');

const bookingSchema = new mongoose.Schema({
    customerId: { type: mongoose.Schema.Types.ObjectId, ref: 'Customer', required: true },
    roomId: { type: mongoose.Schema.Types.ObjectId, ref: 'Room', required: true },
    startDate: { type: Date, required: true },
    endDate: { type: Date, required: true },
    totalAmount: { type: Number, required: true },
});

module.exports = mongoose.model('Booking', bookingSchema);
```

**models/Customer.js**
```javascript
const mongoose = require('mongoose');

const customerSchema = new mongoose.Schema({
    name: { type: String, required: true },
    email: { type: String, required: true, unique: true },
    phone: { type: String, required: true },
});

module.exports = mongoose.model('Customer', customerSchema);
```

### Step 4: Create Controllers
Implement the controller logic to handle requests in the `controllers` directory.

**controllers/roomController.js**
```javascript
const Room = require('../models/Room');

// Create a new room
exports.createRoom = async (req, res) => {
    const room = new Room(req.body);
    try {
        await room.save();
        res.status(201).json(room);
    } catch (error) {
        res.status(400).json({ error: error.message });
    }
};

// Get all rooms
exports.getAllRooms = async (req, res) => {
    try {
        const rooms = await Room.find();
        res.status(200).json(rooms);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
};

// Update a room
exports.updateRoom = async (req, res) => {
    try {
        const room = await Room.findByIdAndUpdate(req.params.id, req.body, { new: true });
        res.status(200).json(room);
    } catch (error) {
        res.status(400).json({ error: error.message });
    }
};

// Delete a room
exports.deleteRoom = async (req, res) => {
    try {
        await Room.findByIdAndDelete(req.params.id);
        res.status(204).send();
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
};
```

### Step 5: Create Routes
Define the routes for rooms, bookings, and customers in the `routes` directory.

**routes/rooms.js**
```javascript
const express = require('express');
const router = express.Router();
const roomController = require('../controllers/roomController');

router.post('/', roomController.createRoom);
router.get('/', roomController.getAllRooms);
router.put('/:id', roomController.updateRoom);
router.delete('/:id', roomController.deleteRoom);

module.exports = router;
```

**Repeat similar steps for bookings and customers.**

### Step 6: Start the Server
Run your application:

```bash
node app.js
```

### Conclusion
This is a basic setup for a hotel management application using Express.js. You can expand on this by adding more features, such as user authentication, payment processing, and front-end integration.

Remember to install MongoDB and have it running locally or use a cloud database service like MongoDB Atlas for production.
