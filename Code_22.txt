To create an Express.js application that implements the specified APIs for the Healthcare API System outlined in the Business Requirements Document (BRD), you can follow the steps below. This example will provide a basic structure and implementation for each of the API modules described in the BRD.

### Step 1: Set Up Your Express Application

1. **Initialize a new Node.js project:**
   ```bash
   mkdir healthcare-api
   cd healthcare-api
   npm init -y
   ```

2. **Install necessary packages:**
   ```bash
   npm install express body-parser mongoose cors dotenv
   ```

3. **Create your project structure:**
   ```bash
   mkdir src
   cd src
   touch app.js routes.js models.js
   ```

### Step 2: Create the Express Application

#### `app.js`
```javascript
const express = require('express');
const bodyParser = require('body-parser');
const cors = require('cors');
require('dotenv').config();

const app = express();
const PORT = process.env.PORT || 3000;

// Middleware
app.use(cors());
app.use(bodyParser.json());

// Routes
const routes = require('./routes');
app.use('/api', routes);

// Start server
app.listen(PORT, () => {
    console.log(`Server is running on port ${PORT}`);
});
```

#### `routes.js`
```javascript
const express = require('express');
const router = express.Router();
const { 
    registerPatient, 
    getPatient, 
    updatePatient, 
    deactivatePatient,
    scheduleAppointment, 
    modifyAppointment, 
    getDoctorAvailability,
    getMedicalRecords, 
    updateMedicalRecords, 
    generatePrescription, 
    getPrescription, 
    generateInvoice, 
    getInvoice,
    processInsuranceClaim
} = require('./controllers');

router.post('/patients', registerPatient);
router.get('/patients/:id', getPatient);
router.put('/patients/:id', updatePatient);
router.delete('/patients/:id', deactivatePatient);

router.post('/appointments', scheduleAppointment);
router.put('/appointments/:id', modifyAppointment);
router.get('/doctors/:id/availability', getDoctorAvailability);

router.get('/patients/:id/records', getMedicalRecords);
router.post('/patients/:id/records', updateMedicalRecords);

router.post('/prescriptions', generatePrescription);
router.get('/prescriptions/:id', getPrescription);

router.post('/billing', generateInvoice);
router.get('/billing/:id', getInvoice);
router.post('/insurance/claims', processInsuranceClaim);

module.exports = router;
```

### Step 4: Set Up Database and Data Models

For simplicity, this example does not include a database connection. You might use MongoDB with Mongoose or any other database. You can create models in `models.js` to define the structure for patients, appointments, medical records, prescriptions, and billing.

### Step 5: Run Your Application

1. **Run your Express app:**
   ```bash
   node src/app.js
   ```

2. **Test the API endpoints using Postman or Curl.**
