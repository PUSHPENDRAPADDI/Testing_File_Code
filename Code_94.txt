### FastAPI Code Implementation

Here’s a basic implementation of the healthcare API system:

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Data Models
class Patient(BaseModel):
    id: int
    name: str
    email: str
    medical_history: str

class Appointment(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    date_time: str

class MedicalRecord(BaseModel):
    patient_id: int
    record: str

class Prescription(BaseModel):
    id: int
    patient_id: int
    medication: str
    dosage: str

class Invoice(BaseModel):
    patient_id: int
    amount: float
    status: str

# In-memory storage (for demonstration purposes)
patients_db = {}
appointments_db = {}
records_db = {}
prescriptions_db = {}
billing_db = {}

# Patient Management
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    patients_db[patient.id] = patient
    return patient

@app.get("/patients/{id}", response_model=Patient)
def get_patient(id: int):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    return patients_db[id]

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: int, patient: Patient):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    patients_db[id] = patient
    return patient

@app.delete("/patients/{id}", response_model=Patient)
def deactivate_patient(id: int):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    deleted_patient = patients_db.pop(id)
    return deleted_patient

# Appointment Scheduling
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    appointments_db[appointment.id] = appointment
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: int, appointment: Appointment):
    if id not in appointments_db:
        raise HTTPException(status_code=404, detail="Appointment not found")
    appointments_db[id] = appointment
    return appointment

@app.get("/doctors/{id}/availability", response_model=List[str])
def get_doctor_availability(id: int):
    # Dummy availability data for demonstration
    return ["2023-01-01T10:00:00", "2023-01-01T11:00:00"]

# Electronic Medical Records (EMR)
@app.get("/patients/{id}/records", response_model=List[MedicalRecord])
def get_medical_records(id: int):
    return [record for record in records_db.values() if record.patient_id == id]

@app.post("/patients/{id}/records", response_model=MedicalRecord)
def add_medical_record(id: int, record: MedicalRecord):
    records_db[len(records_db) + 1] = record
    return record

# Prescription Management
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    prescriptions_db[prescription.id] = prescription
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def get_prescription(id: int):
    if id not in prescriptions_db:
        raise HTTPException(status_code=404, detail="Prescription not found")
    return prescriptions_db[id]

# Billing & Insurance
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    billing_db[len(billing_db) + 1] = invoice
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def get_invoice(id: int):
    if id not in billing_db:
        raise HTTPException(status_code=404, detail="Invoice not found")
    return billing_db[id]

@app.post("/insurance/claims")
def process_insurance_claim(claim: dict):
    # Process insurance claim logic would go here
    return {"status": "Claim processed"}

# Run the application
# Use the command below to run the server:
# uvicorn your_filename:app --reload
```

### Running the Application

Save the code in a file, for instance `healthcare_api.py`, and run it using Uvicorn:

```bash
uvicorn healthcare_api:app --reload
```

### API Testing

You can use tools like Postman or cURL to test the API endpoints. The FastAPI application will also provide an interactive API documentation interface at `http://127.0.0.1:8000/docs`.

### Note
This implementation uses in-memory storage for simplicity. In a production environment, you would typically use a database to store your data persistently. Additionally, security measures such as authentication and authorization would need to be implemented to comply with regulations like HIPAA and GDPR.
