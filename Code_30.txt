Creating a simple cab booking application using FastAPI involves setting up routes for user registration, cab booking, and cab status checking. Below is a basic implementation that demonstrates how to create such an application. This example does not include a database, but you can easily extend it to use a database like SQLite, PostgreSQL, or MongoDB.

First, ensure you have FastAPI and an ASGI server installed. You can install FastAPI and an ASGI server like Uvicorn with the following command:

```bash
pip install fastapi uvicorn
```

Here's a simple FastAPI application for a cab booking service:

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional
import uuid

app = FastAPI()

# In-memory data storage for simplicity
users = {}
cabs = {}
bookings = {}

# Models
class User(BaseModel):
    name: str
    email: str

class Cab(BaseModel):
    id: str
    driver_name: str
    car_model: str
    is_available: bool = True

class Booking(BaseModel):
    user_email: str
    cab_id: str

# Routes
@app.post("/register", response_model=User)
def register_user(user: User):
    if user.email in users:
        raise HTTPException(status_code=400, detail="User already registered")
    users[user.email] = user
    return user

@app.post("/add_cab", response_model=Cab)
def add_cab(cab: Cab):
    if cab.id in cabs:
        raise HTTPException(status_code=400, detail="Cab already exists")
    cabs[cab.id] = cab
    return cab

@app.post("/book_cab", response_model=Booking)
def book_cab(booking: Booking):
    if booking.user_email not in users:
        raise HTTPException(status_code=400, detail="User not registered")
    
    cab = cabs.get(booking.cab_id)
    if not cab or not cab.is_available:
        raise HTTPException(status_code=400, detail="Cab not available")

    # Mark cab as not available
    cab.is_available = False
    bookings[booking.user_email] = booking
    return booking

@app.get("/available_cabs", response_model=List[Cab])
def get_available_cabs():
    available_cabs = [cab for cab in cabs.values() if cab.is_available]
    return available_cabs

@app.get("/booking_status/{user_email}", response_model=Optional[Booking])
def get_booking_status(user_email: str):
    if user_email not in bookings:
        raise HTTPException(status_code=404, detail="No booking found for this email")
    return bookings[user_email]

# To run the application, use the command:
# uvicorn filename:app --reload
# Replace `filename` with the name of your Python file.
```

### Explanation:

1. **User Registration**: Users can register by providing their name and email. The email is used as a unique identifier.

2. **Cab Management**: You can add cabs with a driver name and car model. Each cab has an availability status.

3. **Cab Booking**: Users can book a cab using their email and the cab ID. The cab's availability is updated when booked.

4. **Available Cabs**: This endpoint returns a list of all available cabs.

5. **Booking Status**: Users can check their booking status by providing their email.

### Running the Application

1. Save the code in a file, for example, `cab_app.py`.
2. Run the application using the command:

   ```bash
   uvicorn cab_app:app --reload
   ```

3. Open your browser or API testing tool (like Postman) and navigate to `http://127.0.0.1:8000/docs` to access the automatically generated API documentation.
