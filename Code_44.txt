Let's create a FastAPI application that implements the basic structure for the healthcare API system as outlined in your Business Requirements Document (BRD). Below, you'll find Python code using FastAPI that sets up the necessary endpoints for each of the mentioned API modules: Patient Management, Appointment Scheduling, Electronic Medical Records (EMR), Prescription Management, and Billing & Insurance.

Make sure you have FastAPI and an ASGI server like `uvicorn` installed. You can install these using pip:

```bash
pip install fastapi uvicorn
```

### FastAPI Code Implementation

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Example In-Memory Database
patients_db = {}
appointments_db = {}
records_db = {}
prescriptions_db = {}
billing_db = {}

# Models
class Patient(BaseModel):
    id: int
    name: str
    contact_details: str
    medical_history: str

class Appointment(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    date: str
    time: str

class MedicalRecord(BaseModel):
    patient_id: int
    record: str

class Prescription(BaseModel):
    id: int
    patient_id: int
    doctor_id: int
    prescription_details: str

class Invoice(BaseModel):
    id: int
    patient_id: int
    amount: float

# Patient Management API
@app.post("/patients", response_model=Patient)
def register_patient(patient: Patient):
    if patient.id in patients_db:
        raise HTTPException(status_code=400, detail="Patient already exists")
    patients_db[patient.id] = patient
    return patient

@app.get("/patients/{id}", response_model=Patient)
def retrieve_patient(id: int):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    return patients_db[id]

@app.put("/patients/{id}", response_model=Patient)
def update_patient(id: int, patient: Patient):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    patients_db[id] = patient
    return patient

@app.delete("/patients/{id}", status_code=204)
def deactivate_patient(id: int):
    if id in patients_db:
        del patients_db[id]
    return

# Appointment Scheduling API
@app.post("/appointments", response_model=Appointment)
def schedule_appointment(appointment: Appointment):
    if appointment.id in appointments_db:
        raise HTTPException(status_code=400, detail="Appointment already exists")
    appointments_db[appointment.id] = appointment
    return appointment

@app.put("/appointments/{id}", response_model=Appointment)
def modify_appointment(id: int, appointment: Appointment):
    if id not in appointments_db:
        raise HTTPException(status_code=404, detail="Appointment not found")
    appointments_db[id] = appointment
    return appointment

@app.get("/doctors/{id}/availability")
def get_doctor_availability(id: int):
    # Dummy implementation, should return doctor's availability
    return {"doctor_id": id, "availability": "Available"}

# EMR API
@app.post("/patients/{id}/records", response_model=MedicalRecord)
def add_update_medical_record(id: int, record: MedicalRecord):
    if id not in patients_db:
        raise HTTPException(status_code=404, detail="Patient not found")
    records_db[id] = record
    return record

@app.get("/patients/{id}/records", response_model=MedicalRecord)
def retrieve_medical_records(id: int):
    if id not in records_db:
        raise HTTPException(status_code=404, detail="Records not found")
    return records_db[id]

# Prescription Management API
@app.post("/prescriptions", response_model=Prescription)
def generate_prescription(prescription: Prescription):
    if prescription.id in prescriptions_db:
        raise HTTPException(status_code=400, detail="Prescription already exists")
    prescriptions_db[prescription.id] = prescription
    return prescription

@app.get("/prescriptions/{id}", response_model=Prescription)
def retrieve_prescription(id: int):
    if id not in prescriptions_db:
        raise HTTPException(status_code=404, detail="Prescription not found")
    return prescriptions_db[id]

# Billing & Insurance API
@app.post("/billing", response_model=Invoice)
def generate_invoice(invoice: Invoice):
    if invoice.id in billing_db:
        raise HTTPException(status_code=400, detail="Invoice already exists")
    billing_db[invoice.id] = invoice
    return invoice

@app.get("/billing/{id}", response_model=Invoice)
def retrieve_invoice(id: int):
    if id not in billing_db:
        raise HTTPException(status_code=404, detail="Invoice not found")
    return billing_db[id]

# Run the application
# Use the command: uvicorn filename:app --reload
```

### Running the FastAPI Application

To run your FastAPI application, save the above code to a file (`app.py`, for example) and execute the following command:

```bash
uvicorn app:app --reload
```

The API will be accessible at `http://127.0.0.1:8000/`. You can also access the automatic API documentation provided by FastAPI at `http://127.0.0.1:8000/docs`.

### Note
- This implementation uses an in-memory dictionary to simulate a database. In a production environment, you would typically use a proper database system.
- The authentication and authorization aspects (e.g., using OAuth 2.0/JWT) are not implemented in this example but should be added for a complete and secure API.
- You can expand the functionality with error handling, validation, and more sophisticated business logic as needed.
