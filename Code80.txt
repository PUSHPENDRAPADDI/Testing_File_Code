Creating a simple food delivery app using Express.js involves setting up an Express server, creating routes for handling requests, and possibly connecting to a database to manage food items and orders. Below is a basic example of how you might structure such an app.

### Prerequisites
- Node.js installed on your machine
- Basic knowledge of JavaScript and Express.js

### Step 1: Set Up Your Project

1. **Create a new directory for your project**:
   ```bash
   mkdir food-app
   cd food-app
   ```

2. **Initialize a new Node.js project**:
   ```bash
   npm init -y
   ```

3. **Install Express**:
   ```bash
   npm install express
   ```

4. **Install additional dependencies (optional)**:
   - For body parsing:
     ```bash
     npm install body-parser
     ```
   - For MongoDB (if you want to use a database):
     ```bash
     npm install mongoose
     ```

### Step 2: Create the Express Server

Create a file named `server.js` in your project directory:

```javascript
// server.js
const express = require('express');
const bodyParser = require('body-parser');
const mongoose = require('mongoose');

const app = express();
const PORT = process.env.PORT || 3000;

// Middleware
app.use(bodyParser.json());

// MongoDB connection (replace '<your_connection_string>' with your actual connection string)
mongoose.connect('<your_connection_string>', { useNewUrlParser: true, useUnifiedTopology: true });

// Define a simple Food schema
const foodSchema = new mongoose.Schema({
    name: String,
    description: String,
    price: Number,
});

const Food = mongoose.model('Food', foodSchema);

// Routes

// Get all food items
app.get('/api/foods', async (req, res) => {
    try {
        const foods = await Food.find();
        res.json(foods);
    } catch (error) {
        res.status(500).send(error);
    }
});

// Add a new food item
app.post('/api/foods', async (req, res) => {
    const { name, description, price } = req.body;

    const foodItem = new Food({ name, description, price });

    try {
        const savedFood = await foodItem.save();
        res.status(201).json(savedFood);
    } catch (error) {
        res.status(400).send(error);
    }
});

// Start the server
app.listen(PORT, () => {
    console.log(`Server is running on http://localhost:${PORT}`);
});
```

### Step 3: Run Your Application

1. **Start your server**:
   ```bash
   node server.js
   ```

2. **Test the API**:
   - You can use tools like Postman or curl to test your API.
   - To get all food items:
     ```http
     GET http://localhost:3000/api/foods
     ```
   - To add a new food item:
     ```http
     POST http://localhost:3000/api/foods
     Content-Type: application/json

     {
         "name": "Pizza",
         "description": "Delicious cheese pizza",
         "price": 9.99
     }
     ```

### Step 4: (Optional) Connect to a MongoDB Database

If you're using MongoDB, you need to set up a database. You can use services like MongoDB Atlas for a cloud database. Replace `<your_connection_string>` in the `mongoose.connect()` method with your actual MongoDB connection string.

### Step 5: Expand Functionality

This is a basic setup. You might want to expand the functionality with:
- User authentication
- Order management
- Payment processing
- Advanced error handling
- Frontend integration (using React, Vue.js, etc.)

### Conclusion

This example provides a simple framework for a food delivery app using Express.js. You can expand upon this with more advanced features and integrate it with a frontend framework to create a full-stack application.
