### Test Case: S27_Client Profile_Create_Verify the New Client Profile page navigation from Add New Inquiry page

#### Test Case ID
S27_Client Profile_Create

#### Test Case Description
This test case verifies that the user can navigate from the "Add New Inquiry" page to the "New Client Profile" page after filling out all mandatory fields in the Inquiry form and clicking the "Create Client Profile" button.

#### Pre-requisites
1. User must have valid credentials to access the IntakeApp.
2. User must be on the "Add New Inquiry" page.
3. User must have filled all mandatory Inquiry field details required for Profile creation.

#### Test Steps

1. **Login into IntakeApp**
   - **Action**: Launch the IntakeApp URL.
   - **Expected Result**: The application should launch and the Sign-in screen should be displayed.
  
2. **Sign in to the Application**
   - **Action**: 
     1. Enter the username.
     2. Click the "Next" button.
   - **Expected Result**: 
     - After clicking the "Next" button, the screen should navigate to the Enter Password screen.

3. **Enter Credentials**
   - **Action**: 
     1. Enter the password.
     2. Click the "Sign in" button.
   - **Expected Result**: 
     - Sign-in should be successful.
     - The system will display the dashboard screen as per the roles configured for the logged-in user.

4. **Navigate to Add New Inquiry Page**
   - **Action**: 
     - Ensure that the user is on the "Add New Inquiry" page.
   - **Expected Result**: 
     - The user should be on the "Add New Inquiry" page.

5. **Fill Mandatory Inquiry Fields**
   - **Action**: 
     - Fill out all mandatory fields in the Inquiry form.
   - **Expected Result**: 
     - All mandatory details for profile creation should be filled in the Inquiry form.

6. **Click on 'Create Client Profile' Button**
   - **Action**: 
     - Click the "Create Client Profile" button.
   - **Expected Result**: 
     - The user should be navigated to the "New Client Profile" page.

7. **Verify New Client Profile Page**
   - **Action**: 
     - Check the header and layout of the "New Client Profile" page.
   - **Expected Result**: 
     - The user is on the "New Client Profile" page.
     - All relevant sections (e.g., Client ID, Inquiry Date, etc.) should be present as specified in the user story.

#### Post-conditions
- The "New Client Profile" page is displayed, allowing the CAC to enter additional details for the client's profile.

#### Business Rules
- The Client Profile must have a unique ID created for the client in both the product and the EMR.
- Only a maximum of 3 payors can be added to the client profile.

#### Dependencies
- The information added to the inquiry form must be accurate and complete to facilitate the creation of the client profile.

### Notes
- Duplicate check functionality for the client profile will be implemented and tested as part of a separate user story (User Story ID: 1194).
